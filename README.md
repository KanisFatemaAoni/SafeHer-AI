 💙 SafeHer AI

 Intelligent Personal Safety & Emergency Assistance

Your Safety. Your Voice. Your Power.

 🌍 About the Project

SafeHer AI is a personal safety technology prototype exploring how artificial intelligence and digital tools can support personal security.

 🚀 Core Features

- 🆘 Emergency SOS demonstration
- 👥 Trusted Contacts Management
- ⏱️ Safety Journey Monitoring
- 🤖 AI Safety Assistant interface

 🛠️ Technologies Used

- Python
- Streamlit
- Pandas

 📌 Current Project Status

Prototype under development.

Some features are simulated and do not provide real emergency response services.

 ▶️ How to Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```
